# Run Locally

The portfolio can be served using any static web server.

### Using Python

```bash
python3 -m http.server 8080 --directory dist
```

Open:

```text
http://localhost:8080
```

A web server is recommended because the portfolio uses root-relative paths for navigation and assets.

# Deployment

The portfolio is designed as a static website.

No backend server or database is required for the portfolio itself.

### Deployment configuration

```text
Build command:
None

Publish directory:
dist

Runtime dependency:
None
```

The `projects` and `assets` directories should remain intact during deployment.
